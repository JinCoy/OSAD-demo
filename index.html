01 · ANALYSIS CALIBRATION

분석 알고리즘의 기준값을 비교하세요

개발 검증용 설정입니다. Raw는 현재 측정값, Calibrated는 noise gate·범위·curve를 적용해 Song DNA에 들어가는 값입니다. 아래 설정은 Avatar Mutation Lab의 표시 민감도와 독립적입니다.

축별 분석 범위와 Curve

Min–Max는 분석 입력을 다시 0–1로 펼치고, Curve가 높을수록 작은 값이 강조됩니다.

Song DNA 집계 가중치

분석 세션이 끝난 뒤 프레임 통계를 하나의 곡 값으로 요약하는 비율입니다.

Session comparison 완료된 분석을 최대 6개까지 현재 탭에서 비교합니다.

아직 완료된 분석이 없습니다.
